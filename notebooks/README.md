# Experiments

All three notebooks run in `sample` mode out of the box. They use shared, tested code from `src/pipeline.py` and write new outputs to `results/sample/`.

Run all code cells and save visible outputs from the project root:

```powershell
python tools/run_notebook.py
```

For interactive work, open a notebook in VS Code with the Jupyter extension. Read the root [README](../README.md) before switching `DATA_MODE` to a full dataset.
